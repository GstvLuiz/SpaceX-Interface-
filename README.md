# 🚀 SpaceX Interface

Interface web inspirada na SpaceX, desenvolvida como trabalho acadêmico da disciplina de **Front-End**, durante o **2º semestre** ministrada no curso de **Análise e Desenvolvimento de Sistemas** da  **Universidade Católica do Salvador (UCSAL)**.

## 🛰️ Sobre o Projeto

Este projeto tem como objetivo simular uma interface moderna para uma empresa de exploração espacial, utilizando **HTML5** e **CSS3** puro. A proposta foi exercitar os conhecimentos em estruturação de páginas, estilização e design responsivo.

## 🎯 Funcionalidades

- Página principal com **banner de destaque** e **citação inspiradora**
- Cards de **missões espaciais**
- **Formulário de viagem espacial** para futuros astronautas
- **Rodapé informativo**
- Layout **totalmente responsivo**, adaptado para dispositivos móveis e desktop

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (com media queries para responsividade)
- Estrutura sem frameworks ou bibliotecas externas
